# CodeBrick 答题键盘模拟（油猴脚本）

在 <https://www.codebrick.tech/> 的答题页上，按你给的答案自动模拟键盘：
`字母 → Enter → →`，循环 N 题。答案由你提供，提交仍由你自己点。

底层原理：在网页内部派发合成的 `KeyboardEvent`（`isTrusted = false`）。CodeBrick 用
`keydown` 监听选项，所以能用；如果哪天站点开始校验真人按键，这个方案会被拦。

---

## 文件

| 文件 | 说明 |
|---|---|
| `auto-answer.user.js` | 脚本本体（v1.6.1），ScriptCat / Tampermonkey / Violentmonkey 通用 |

`@match` 已限定 `codebrick.tech`，别的网站不会加载。

---

## 安装

1. 打开 ScriptCat 管理面板 → 右上「+」新建脚本
2. 把 `auto-answer.user.js` 的内容整个粘进去 → `Ctrl+S` 保存
3. 刷新答题页

> 也可以直接把 `.user.js` 拖进浏览器窗口，管理器会弹安装页。
> **不要同时留两份**（旧版 + 新版），否则会出现两个「答」圆块、每按一次键跑两遍。

---

## 用法

1. 打开 CodeBrick 答题页（原生支持 A/B/C/D 选答案，不需要先点题目区域）
2. 点**左上角**那个浮动的 **「答」圆块** 打开面板；不想点就按 **Alt + Shift + A**
3. 把答案粘进输入框——下面会按题号排成一张**答案卡**，右上角写着现在读进几个题
4. 只想答其中几题，就把「只发 第 X 到 Y 题」改一下（见 [只答其中几题](#只答其中几题)），不改就是全部
5. 点 **「单步」**：只发一轮 `字母 → Enter → →`，确认选项真被选中、也真翻到下一题
6. 确认无误 → 点 **「开始」**，40 题按 2200ms 每题算约 90 秒跑完
7. 自己检查一遍，**手动点提交**（脚本不碰提交按钮）

## 面板

主界面只放高频的东西，其余参数都收在底部「设置」里（收起来的状态会被记住）。

| 位置 | 内容 |
|---|---|
| 右上角 | 已读入的题数；跑的时候变成 `12 / 40` |
| 输入框 | 粘答案，只认 A/B/C/D；`-` `_` `?` 表示「这题跳过」，空格、题号、换行自动忽略 |
| 答案卡 | 按 10 列排、每 5 题隔开一点，每格上面是题号、下面是答案；**点某一格会 A→B→C→D→—（跳过） 循环** |
| 每题间隔 | **限速开关**，默认 2200ms ≈ 27 题/分；右侧「≈ N 题/分」变红就是太快 |
| 只发 第 X 到 Y 题 | 只发这一段；默认跟着答案数走，粘几题就是几题 |
| 现在 第 N 题 | 从页面读到的题号（读不到显示 `现在 ?`）；开跑前会按它自动翻到位 |
| 开始 | 从范围起点一路跑到范围终点 |
| 单步 | 只发一轮按键，用来确认站点吃不吃这套；连点就一题一题走（走到范围末尾绕回起点） |
| 停止 / Esc | 立刻中断 |

设置里：

| 选项 | 作用 |
|---|---|
| 字母后 / Enter 后 / → 后 | 三个步骤之间的等待毫秒数，站点慢就调大 |
| 大写 | 站点用 `e.key === 'A'` 判断时勾上（默认发小写 `a`） |
| 不发 Enter | 选完直接按 `→` 就能跳题时勾上 |
| 不发 → | 站点自己会跳题时勾上，否则会一次跳两题 |
| 快捷键 | 点这一格，直接按下你要的组合（要带 Ctrl/Alt/Shift 或 F1~F12），会被记住 |
| 自检 | 只发一个 `a`，观察 0.8 秒看页面有没有变化，判断合成按键管不管用 |
| 归零 | 单步的进度回到范围开头 |

配置、答案、快捷键都存在浏览器本地（`localStorage`），下次打开还在。面板可以按住标题条拖走。

## 只答其中几题

以前是「粘 40 题、从头跑到尾」。现在可以只发其中一段，甚至只发不连续的几题：

| 想要 | 怎么设 |
|---|---|
| 只跑第 13–15 题 | 粘完整答案 → 「只发 第 **13** 到 **15** 题」→ 开始 |
| 只跑第 13 题 | 「只发 第 13 到 13 题」 |
| 跑 13、15，14 跳过 | 「只发 第 13 到 15 题」，答案里第 14 个写成 `-`（`C-C`） |
| 手里本来只有 3 个答案 | 直接粘 3 个，范围自动变成「第 1 到 3 题」，从页面当前那题开始发 |

要注意的一点：题号只是答案卡上的序号，页面停在第几题是另一回事。
脚本会读页面角标上的题号自己翻过去（见下一节）；万一读不到（面板显示 `现在 ?`），就先把页面翻到那一题再点「开始」。
不放心就先点「单步」试一题，看选中的是不是你要的那道。

答案一变（重新粘贴），范围会自动回到「全部」，免得上一次的 13–15 把这一次也裁短。

## 自动对位（v1.6.0）

CodeBrick 把题号写在题目角标上：

```html
<article><header>
  <span class="source-badge sb-real" title="2015 年统考真题 · 第 5 题">真题 2015 · 第 5 题</span>
</header>…</article>
```

脚本读这个角标里「第 N 题」的 N，显示成面板上的 `现在 第 N 题`，换题时跟着变。开跑前按它对齐：

| 情况 | 脚本怎么做 |
|---|---|
| 页面在第 1 题，范围从第 5 题开始 | 先按 4 次 `→` 翻到第 5 题，再开始发 |
| 页面正好在范围起点 | 一次 `→` 都不多按 |
| 页面已经越过起点（在第 9 题，范围从第 5 题开始） | **不发**，直接停下来说「请先手动翻到第 5 题」 |
| 按了 `→` 但题号没变／翻过头 | 立刻停下，说明卡在哪一题 |
| 读不到题号（显示 `现在 ?`） | 退回老办法：你自己翻好，脚本把当前这题当范围第一题，结束时状态栏会写明 |

这样「停在第一题、只发第 5–8 题」可以直接点开始，脚本自己翻过去；也不会再出现"页面在第 9 题却从第 5 题开始发、四道全错"这种事。

题号是**猜着读**的：先试 `article header .source-badge`，再试 `.source-badge`、`[class*="source-badge"]` 等几种常见写法（见脚本里的 `Q_SEL`）。站点改版换了 class，把新的选择器加到 `Q_SEL` 最前面即可；真的找不到也不影响其它功能，只是退回手动对位。

## 限流：30 次/分

CodeBrick 限每分钟 30 次答题，超了会挡一段时间。

`每题间隔` 量的是「这一题开始按键」到「下一题开始按键」的总时长，不够由脚本自动补足。
所以把 `字母后 / Enter 后 / → 后` 调大只会拖慢单题，**不会**让整体节奏超过设定值。

| 间隔 | 题/分 | 40 题耗时 |
|---|---|---|
| 2000ms | 30 | 80 秒（正好卡限额，不建议） |
| **2200ms（默认）** | **27** | **88 秒** |
| 2500ms | 24 | 100 秒 |
| 3000ms | 20 | 120 秒 |

被限流之后**先歇几分钟再跑**，别连着硬冲。第一次跑可以先用 2500ms 留余量。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 面板打不开 | 快捷键被站点占了 → 直接点左上角「答」圆块；或在「设置」里改快捷键 |
| 「自检」说没反应 | 站点校验真人按键（`isTrusted`），合成事件被无视 → 此方案无效 |
| 一次跳两题 | 站点自己会跳题，勾上「不发 →」 |
| 答案串位 | 站点渲染慢：把「→ 后」调大（1200ms 起试） |
| 选项没选中但翻页了 | 输入法的中文态无关（合成事件不走输入法）；多半是站点按 `e.key === 'A'` 判断，勾上「大写」 |
| 只选中了没翻页 | 站点不需要 Enter，勾上「不发 Enter」 |
| 题数不对 | 看右上角数字；答案卡跟着输入框重排。只想跑一段就把「只发」设成 X 到 Y |
| 跑到一半发现页面题号不对 | 面板上的 `现在 第 N 题` 是读出来的；对不上就先停下，用手动翻页对齐 |
| 面板上显示 `现在 ?` | 没在页面上找到「第 N 题」——站点改版或题号不是文本。把新的选择器加到 `Q_SEL`，或手动翻好再跑 |
| 点开始却提示「已经过了起点」 | 页面在范围起点之后（脚本不往回翻）：手动翻回去，或把「只发」起点改成当前题号 |
| 站点必须用鼠标点选项 | 键盘模拟无效，需要改成鼠标点击自动化 |

## 版本管理

这个目录本身就是一个 git 仓库（`main` 分支），当前版本 `v1.6.1`，版本号同步写在脚本头部的 `// @version`。

```bash
# 看历史 / 看标签
git -C auto-answer log --oneline --decorate
git -C auto-answer tag

# 改完提交
git -C auto-answer add -A
git -C auto-answer commit -m "改了什么"

# 发版：改 // @version 后再打标签
git -C auto-answer tag -a v1.6.2 -m "v1.6.2"
```

历史版本随时可以取回：

```bash
git -C auto-answer show v1.5.0:auto-answer.user.js > 旧版.user.js
```
