# 码砖速填

把已有答案成批敲进 [CodeBrick](https://www.codebrick.tech/) 的答题页。选项和翻页交给脚本，核对与提交仍是你。

按 `字母 → Enter → →` 的节奏回放你粘贴的 A/B/C/D，可以只发指定的题号范围，也可以跳过个别题。页面角标能读出「第 N 题」时，脚本自己翻到起点，过了起点按 `←` 退回来。

支持 ScriptCat、Tampermonkey、Violentmonkey。

## 安装

把 `.user.js` 拖进浏览器窗口，或者在脚本管理器里新建脚本、把整份内容粘进去。

从 URL 安装：

```
https://raw.githubusercontent.com/Neptune153/codebrick-quick-fill/main/codebrick-quick-fill.user.js
```

只留一份。新旧同时装会出两个「答」圆块，一次按键跑两遍。

## 更新

改完脚本把 `@version` 调大再推到 main，脚本管理器按自己的「更新间隔」去检查，看到新版本就问你要不要更新。

检查地址写在头部：`@updateURL` 和 `@downloadURL` 都指向这份 `.user.js`。1.8.0 及以前的版本没有这两行，管理器会照惯例去找同目录的 `codebrick-quick-fill.meta.js`，所以仓库里留了一份，用 `node tools/gen-meta.mjs` 从头部生成——改完版本号记得跑一次，别让它和主文件对不上。

推完 raw 有几分钟缓存，不想等就在脚本详情里点「检查更新」。

## 用法

1. 打开答题页，不需要先点题目区域
2. 点左上角浮动的「答」圆块，或按 `Alt + Shift + A`
3. 把答案粘进输入框，只认 A/B/C/D，`-` `_` `?` 表示跳过这题
4. 只答其中几题就改「只发 第 X 到 Y 题」，不改就是全部
5. 点「单步」发一题，确认选项被选中、页面也翻到了下一题
6. 点「开始」，2200ms 一题，40 题约 88 秒
7. 自己核对一遍，手动提交

## 只发其中几题

| 想要 | 怎么设 |
|---|---|
| 只跑第 13–15 题 | 粘完整答案，「只发」13 到 15 |
| 只跑第 13 题 | 「只发」13 到 13 |
| 跑 13、15，14 跳过 | 「只发」13 到 15，第 14 个答案写 `-` |
| 手里只有 3 个答案 | 直接粘 3 个，范围自动变成 1 到 3 |

题号指答案卡上的序号。重新粘答案时范围会回到全部，免得上一段的设置把这一段裁短。

## 自动对位

题号写在题目角标上：

```html
<span class="source-badge" title="2015 年统考真题 · 第 5 题">真题 2015 · 第 5 题</span>
```

读到就显示成面板上的 `现在 第 N 题`，换题跟着变。开跑前按它对齐：没到起点按 `→` 往前翻，过了起点按 `←` 退回来，每按一次等「翻页」那么久，确认题号变了再按下一次，落到起点后再等一拍才发第一个字母。

读不到题号就退回手动：自己翻好，脚本把当前这题当范围第一题。按了键题号不变会停下并说明卡在哪一题。

选择器按 `article header .source-badge` → `.source-badge` → `[class*="source-badge"]` 逐级试，站点改版后把新写法加到脚本的 `Q_SEL` 最前面。

## 面板

| 位置 | 内容 |
|---|---|
| 右上角 | 读入的题数，跑起来显示 `12 / 40` |
| 输入框 | 粘答案，空格、题号、换行自动忽略 |
| 答案卡 | 10 列，每 5 题隔开；点一格按 A → B → C → D → 跳过 循环 |
| 每题间隔 | 默认 2200ms 约 27 题/分，右边的折算值变红表示太快 |
| 只发 第 X 到 Y 题 | 默认跟着答案数走 |
| 现在 第 N 题 | 从页面读到的题号，读不到显示 `现在 ?` |
| 开始 / 单步 / 停止 | 单步一次一轮，走过范围末尾绕回起点；停止或 Esc 中断 |

底部「设置」里放着其余参数，开合状态会记住：

| 选项 | 作用 |
|---|---|
| 字母后 / Enter 后 / → 后 | 三步之间的等待毫秒数，站点慢就调大 |
| 翻页 | 对位时每按一次 `←`／`→` 等多久，默认 1500ms |
| 大写 | 站点用 `e.key === 'A'` 判断时勾上，默认发小写 |
| 不发 Enter | 选完直接按 `→` 就能跳题时勾上 |
| 不发 → | 站点自己会跳题时勾上，否则一次跳两题 |
| 快捷键 | 点这一格按下新组合，要带 Ctrl/Alt/Shift 或 F1~F12 |
| 自检 | 真按一下 `A`，看页面有没有反应 |
| 归零 | 单步进度回到范围开头 |

答案、配置、快捷键存在浏览器本地 `localStorage`，下次打开还在。面板可以按住标题条拖走。

## 限流

CodeBrick 限每分钟 30 次答题，超了会挡一段时间。

「每题间隔」量的是这一题开始按键到下一题开始按键的总时长，不够由脚本补足。把三个等待时间调大只会拖慢单题，不会让整体节奏超过设定值。

| 间隔 | 题/分 | 40 题耗时 |
|---|---|---|
| 2200ms | 27 | 88 秒 |
| 2500ms | 24 | 100 秒 |
| 3000ms | 20 | 120 秒 |

第一次跑用 2500ms 留余量，被限流后歇几分钟再跑。

## 常见问题

| 现象 | 处理 |
|---|---|
| 面板打不开 | 快捷键被站点占了，点「答」圆块，或在设置里改快捷键 |
| 自检说没反应 | 站点校验真人按键，合成事件被无视 |
| 一次跳两题 | 勾上「不发 →」 |
| 答案串位 | 调大「→ 后」，从 1200ms 起试 |
| 只选中了没翻页 | 勾上「不发 Enter」 |
| 没选中但翻页了 | 勾上「大写」 |
| 点开始后先干等几秒 | 对位在按「翻页」间隔走，嫌慢把它调小 |
| 显示 `现在 ?` | 手动翻到起点再跑，或把新选择器加到 `Q_SEL` |
| 提示「退不回去」 | 站点不认 `←`，手动翻回起点，或把「只发」起点改成当前题号 |

## 原理与边界

按键是页面内部派发的合成 `KeyboardEvent`，`isTrusted` 为 `false`。站点校验真人按键时这条路走不通，得改用 AutoHotkey 一类的系统级模拟；站点要求鼠标点选项时同理。

`@match` 限定在 `codebrick.tech`，别的网站不会加载。脚本不碰提交按钮，提交前请自己核对。
