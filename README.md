# CodeBrick 答题键盘模拟

在 <https://www.codebrick.tech/> 的答题页上按你给的答案自动模拟键盘：`字母 → Enter → →`，循环 N 题。
答案由你粘贴，提交由你自己点。可以只发某一段题号，也可以跳过个别题。

支持 ScriptCat、Tampermonkey、Violentmonkey。

---

## 安装

1. 打开脚本管理器，新建脚本
2. 把 `auto-answer.user.js` 整个粘进去，保存
3. 刷新答题页

也可以把 `.user.js` 拖进浏览器窗口，管理器会弹安装页。

不要同时装两份旧版和新版，会出两个「答」圆块，一次按键跑两遍。

---

## 用法

1. 打开答题页，不需要先点题目区域
2. 点左上角浮动的「答」圆块打开面板，或按 `Alt + Shift + A`
3. 把答案粘进输入框，下面会按题号排成答案卡
4. 只答其中几题时，把「只发 第 X 到 Y 题」改一下，不改就是全部
5. 点「单步」发一题，确认选项真的被选中、页面也真的翻到下一题
6. 点「开始」，40 题按 2200ms 每题约 88 秒
7. 自己检查一遍，手动点提交

## 面板

主界面只放常用的几项，其余参数收在底部「设置」里，开合状态会记住。

| 位置 | 内容 |
|---|---|
| 右上角 | 已读入的题数，跑起来后显示 `12 / 40` |
| 输入框 | 粘答案，只认 A/B/C/D；`-` `_` `?` 表示跳过这题；空格、题号、换行自动忽略 |
| 答案卡 | 按 10 列排，每 5 题隔开；点一格按 A → B → C → D → 跳过 循环 |
| 每题间隔 | 限速开关，默认 2200ms，约 27 题/分；右边的「≈ N 题/分」变红表示太快 |
| 只发 第 X 到 Y 题 | 只发这一段，默认跟着答案数走 |
| 现在 第 N 题 | 从页面读到的题号，读不到显示 `现在 ?` |
| 开始 | 从范围起点跑到范围终点 |
| 单步 | 只发一轮按键，连点就一题一题走，走到范围末尾绕回起点 |
| 停止 / Esc | 立刻中断 |

设置里：

| 选项 | 作用 |
|---|---|
| 字母后 / Enter 后 / → 后 | 三个步骤之间的等待毫秒数，站点慢就调大 |
| 翻页 | 对位时每按一次 `←`／`→` 等多久，默认 1500ms，最小 300ms |
| 大写 | 站点用 `e.key === 'A'` 判断时勾上，默认发小写 `a` |
| 不发 Enter | 选完直接按 `→` 就能跳题时勾上 |
| 不发 → | 站点自己会跳题时勾上，否则一次跳两题 |
| 快捷键 | 点这一格按下新的组合键，要带 Ctrl/Alt/Shift 或 F1~F12 |
| 自检 | 真按一下 `A`，观察 0.8 秒看页面有没有反应 |
| 归零 | 单步进度回到范围开头 |

答案、配置、快捷键存在浏览器本地 `localStorage`，下次打开还在。面板可以按住标题条拖走。

## 只发其中几题

| 想要 | 怎么设 |
|---|---|
| 只跑第 13–15 题 | 粘完整答案，「只发」改成 13 到 15 |
| 只跑第 13 题 | 「只发」13 到 13 |
| 跑 13、15，14 跳过 | 「只发」13 到 15，答案里第 14 个写 `-`，例如 `C-C` |
| 手里只有 3 个答案 | 直接粘 3 个，范围自动变成 1 到 3 |

题号指的是答案卡上的序号。页面停在第几题由脚本读角标判断，读不到就自己先把页面翻到起点。

重新粘贴答案时范围会回到全部，免得上一段的设置把这一段裁短。

## 自动对位

CodeBrick 把题号写在题目角标上：

```html
<article><header>
  <span class="source-badge sb-real" title="2015 年统考真题 · 第 5 题">真题 2015 · 第 5 题</span>
</header>…</article>
```

脚本读这里的 N，显示成面板上的 `现在 第 N 题`，换题时跟着变。开跑前按它对齐：

| 情况 | 脚本怎么做 |
|---|---|
| 页面在第 1 题，范围从第 5 题开始 | 按 4 次 `→` 翻到第 5 题再发 |
| 页面正好在范围起点 | 不按 |
| 页面已越过起点，例如在第 16 题、范围从第 5 题开始 | 按 11 次 `←` 退到第 5 题再发 |
| 按了键题号没变 | 停下并说明卡在哪一题 |
| 读不到题号，显示 `现在 ?` | 当前这题当范围第一题，结束时状态栏写明 |

`→` 和 `←` 都是一下一下按着等的，每按一次等「翻页」那么久，确认题号变了再按下一次，落到起点后再等一拍才发第一个字母。20 题的跨度约 30 秒，换来的是不会在页面还没渲染完时读错题号，也不会连着猛冲触发风控。

「只发第 X–Y 题 · 会先翻到第 X 题」这行小字只在准备阶段出现，点开始后清空，跑的过程中只有 `现在 第 N 题` 和底部状态栏在走。

题号是逐级猜着读的：先试 `article header .source-badge`，再试 `.source-badge`、`[class*="source-badge"]` 等几种写法。站点改版后把新选择器加到脚本的 `Q_SEL` 最前面即可，找不到也只是退回手动对位。

## 限流

CodeBrick 限每分钟 30 次答题，超了会挡一段时间。

「每题间隔」量的是「这一题开始按键」到「下一题开始按键」的总时长，不够由脚本补足。把 `字母后 / Enter 后 / → 后` 调大只会拖慢单题，不会让整体节奏超过设定值。

| 间隔 | 题/分 | 40 题耗时 |
|---|---|---|
| 2000ms | 30 | 80 秒，正好卡限额，不建议 |
| 2200ms | 27 | 88 秒 |
| 2500ms | 24 | 100 秒 |
| 3000ms | 20 | 120 秒 |

被限流后先歇几分钟再跑。第一次跑可以先用 2500ms 留余量。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 面板打不开 | 快捷键被站点占了，点左上角「答」圆块，或在设置里改快捷键 |
| 自检说没反应 | 站点校验真人按键，合成事件被无视，此方案无效 |
| 一次跳两题 | 站点自己会跳题，勾上「不发 →」 |
| 答案串位 | 站点渲染慢，把「→ 后」调大，从 1200ms 起试 |
| 选项没选中但翻页了 | 站点按 `e.key === 'A'` 判断，勾上「大写」 |
| 只选中了没翻页 | 站点不需要 Enter，勾上「不发 Enter」 |
| 点开始后先干等好几秒 | 对位在按「翻页」间隔一下一下走，嫌慢把「翻页」调小 |
| 显示 `现在 ?` | 页面上没找到「第 N 题」，把新选择器加到 `Q_SEL`，或手动翻好再跑 |
| 提示「退不回去」 | 站点不认 `←`，或按了题号也不变，手动翻回起点，或把「只发」起点改成当前题号 |
| 跑到一半题号对不上 | 先停下，用 `单步` 确认，再手动翻到起点重跑 |
| 站点必须用鼠标点选项 | 键盘模拟无效，需要鼠标点击自动化 |

## 原理与边界

按键是网页内部派发的合成 `KeyboardEvent`，`isTrusted` 为 `false`。用 `keydown` / `keyup` 监听选项的站点都能用；如果站点校验真人按键，这条路走不通，得改用 AutoHotkey 一类的系统级按键模拟。

`@match` 限定在 `codebrick.tech`，别的网站不会加载。题号画在 canvas 上或换了 class 时自动对位失效，其余功能不受影响。

脚本不碰提交按钮，提交前请自己核对。
